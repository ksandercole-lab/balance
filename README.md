# Balance PWA

Бесплатная устанавливаемая веб-версия Balance для iPhone. Данные сохраняются только в локальном хранилище браузера пользователя.

## Возможности

- долги «Мне должны» и «Я должен», редактирование и история погашенных долгов;
- копилка с ручной начальной суммой и автоматическим добавлением фактического остатка закрытых месяцев;
- независимые итоги для EUR, USD, RUB, GBP и TRY;
- доходы и расходы отдельно для каждого месяца;
- разовые и ежемесячные платежи с чекбоксами оплаты;
- расчёт плана, оплаченной суммы, экономии или убытка;
- просмотр и планирование будущих месяцев;
- календарь с отметками дел, разовых расходов и сроков долгов;
- важные дела с датой и временем;
- автономная работа после первого открытия;
- сохранение и восстановление резервной копии через приложение «Файлы»;
- автоматическая светлая и тёмная тема.

## Публикация

Папка должна размещаться на HTTPS-хостинге. Подойдут бесплатные GitHub Pages, Cloudflare Pages или Netlify. Загружать нужно содержимое папки `pwa`, чтобы рядом с `index.html` находились `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` и папка `icons`.

После публикации откройте адрес на iPhone именно в Safari, нажмите кнопку «Поделиться», затем «На экран Домой» и «Добавить».

## Локальная проверка

Из папки `pwa`:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`. Простое открытие `index.html` как файла не включает автономный режим.

## Важно о данных

Записи не передаются на сервер и не синхронизируются между устройствами. Удаление данных Safari или сайта удалит записи Balance. Не очищайте данные сайта без необходимости.
